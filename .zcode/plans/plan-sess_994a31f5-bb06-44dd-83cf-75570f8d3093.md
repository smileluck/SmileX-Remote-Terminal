# 设置页布局排版优化

将设置页从「顶部三条横条堆叠」(header → 外观横条 → 分区切换横条)重构为「左侧分区导航 + 右侧内容区」,与 LLM 分区已有的双栏结构自然融合,风格对齐应用的 Termius 深色运维风。**所有业务逻辑零改动,纯布局/样式重构。**

## 改动文件(3 个)

### 1. `app/src/styles/main.css` — token 与工具类补充
- `:root` 补定义 `--font-mono: ui-monospace, "SF Mono", Menlo, Consolas, monospace;`(目前多处引用 `var(--font-mono, monospace)` 但变量从未定义)
- 新增 `--primary-border` token:深色 `rgba(76, 141, 255, 0.35)`、`.theme-light` 下 `rgba(46, 107, 230, 0.35)`,替代散落的硬编码主色边框
- 新增全局工具类 `.settings-card` / `.settings-card-title` / `.settings-card-desc`,供各设置分区复用统一卡片样式

### 2. `app/src/components/settings/SettingsView.vue` — 布局重构
**新结构:**
```
.settings-view (flex row)
├─ .settings-nav (~180px, bg-sidebar + 右边框)
│   ├─ 「设置」小标题
│   └─ 导航项(图标+文字): Palette→外观 / Robot→LLM 配置 / Key→SSH 密钥
│       active: --primary-bg + 主色文字;hover: --bg-elevated
└─ .settings-content (flex column)
    ├─ 分区 header:标题(17px/600) + 描述(13px secondary),按分区切换文案
    ├─ [外观]  主题选择 → 三个可点击预览卡片(深色/浅色/跟随系统,各带 mini 色块),调 themeStore.setMode 逻辑不变
    ├─ [LLM]   保持 master-detail 双栏(档案列表 240px + 编辑区)
    └─ [密钥]  KeyManager
```

**LLM 编辑区排版统一:**
- 手写 form + `.field`/`.label` 改为 `NForm`/`NFormItem`(label-placement="top"、size="small"),与 ConnectForm 风格一致;名称必填校验保持现有手动检查
- actions 重排:左侧「保存(primary)/ 测试连接」,右侧「设为默认 / 删除(popconfirm)」,space-between 分离主操作与危险操作
- `.profile-item.active` 的 border-color 硬编码 `rgba(58,122,254,.3)` → `var(--primary-border)`
- 更新过时文案:「API Key 加密存储于系统凭据库(Keyring)」→「加密存储于本地」(凭据已改为本地 AES vault)

**删除:** 旧 `.appearance` 横条结构及关联样式。

### 3. `app/src/components/settings/KeyManager.vue` — 排版对齐
- 三个区块(生成 / 导入 / 已存列表)套用全局 `.settings-card`,与其他分区视觉统一
- 去除全部内联样式(`style="flex: 1"`、mono 字体、NSpin/NEmpty 的 padding)改为 class
- 头部注释中过时的「私钥存 OS Keyring」描述同步更正

### 统一排版体系
分区标题 17px/600 · 分区描述 13px · 卡片标题 13px/600 · 辅助文字 12px · 间距 8px 节奏(内容区 padding 24px、卡片间 gap 16px、卡片内 padding 16px)。

## 验证
1. `cd app && pnpm type-check`(vue-tsc --noEmit)
2. 根目录 `pnpm tauri dev` 启动,截图检查三个分区在深/浅主题下的表现:导航 active 态、主题预览卡片、表单对齐、actions 排布、密钥卡片
