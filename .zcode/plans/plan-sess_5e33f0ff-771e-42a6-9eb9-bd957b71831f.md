# 重构方案：统一 SSH 连接入口 + Tab 去重 + Agent 右侧面板关联远程服务器

前端为 Vue 3 + Pinia + naive-ui（app/src），Rust 侧 desktop/ai-core/ssh-core（crates/）。

## A. 统一「新建 SSH」入口（唯一入口 = 全局弹窗表单）

**新增**
- `app/src/stores/ui.ts`：Pinia store — `connectVisible` / `connectProfileId`（编辑模式）、`openConnectDialog(profileId?)`、`closeConnectDialog()`
- `app/src/components/common/ConnectDialog.vue`：`NModal`（preset card，约 680px 宽）内嵌现有 `ConnectForm` 表单体；在 `App.vue` 挂载一份

**改动**
- `ConnectForm.vue`：
  - `doConnect` 不再自己 `addTab`，改调统一函数 `connectAndOpen(profile, secret)`（见 B），修复「仅连接」建 tab 不带 profileId 导致断线无法重连的 bug；「仅连接」仍先落库 profile（现状已 save，补上 id 关联）
- 入口全部收敛到弹窗 / 统一函数：
  - `ActivityRail.vue:27`、`MainContent.vue:41` 欢迎页、`App.vue:57` ⌘T → `openConnectDialog()`（**取消「空 ssh tab」概念**，不再 `addTab('ssh', '新 SSH 会话')`）
  - `SideBar.vue:96` 新建、`:258` 编辑 → 打开弹窗（删除侧栏内嵌表单渲染）
  - `SideBar.vue:134` onConnect、`CommandPalette.vue:127` connectHost → 改调统一连接函数（顺带修复 CommandPalette 不 touch / 不设监控的不一致）
- 删除两份复制粘贴的内联表单：
  - `TerminalView.vue:178-204` 表单 + `handleConnect` 删除，无会话时显示「新建连接」按钮（开弹窗）
  - `PaneTerminal.vue:129-153` 表单 + `quickConnect` 删除，保留「绑定现有会话」下拉 + 「新建 SSH 连接」按钮（开弹窗）
- RDP 流程（DesktopView）不在本次范围，保持不动

## B. Tab 去重：重复连接弹「切换 or 新开」

- `app/src/composables/useSshConnect.ts` 新增统一入口 `connectProfileSmart(profile)`：
  1. 查 `tabs.find(t => t.profileId === profile.id && t.sessionId && !t.disconnected)`
  2. 命中 → `useDialog` 二选一：「切换到已有会话」（setActive + monitor.setActive）/「新建连接」（connect + addTab）
  3. 同 profile 存在但已断线的 tab → 直接复用该 tab 原地重连（updateTab 换 sessionId，参照 `TerminalView.vue:157` handleReconnect 现有写法）
  4. 无 → `connectProfile` + `addTab(kind, name, sid, profileId)` + `monitor.setActive` + `profileService.touch`
- 所有连接入口（SideBar / CommandPalette / ConnectDialog）统一走它，消除三处 `addTab` 的行为差异

## C. Agent 助手移到右侧（与监控做切换栏）

- `stores/layout.ts`：新增 `rightTab: 'agent' | 'monitor'`（持久化）；`monitorVisible/monitorWidth` 沿用（语义变为右栏）
- `MonitorPanel.vue` 改造为 `RightPanel.vue`：顶部切换栏（「Agent」「监控」）+ 保留拖宽；内容区渲染 AgentPanel | 现有 MonitorDashboard；`App.vue:174` 挂载点替换
- `ActivityRail.vue:45` Robot 图标 → 打开右栏并切到 Agent（不再 `addTab('chat')`）；`MainContent.vue:49` AI 欢迎按钮同理；可加 ⌘J 快捷键切 Agent
- 删除 chat tab：`SessionKind` 移除 `'chat'`、`MainContent.vue:29-32` 移除 ChatPanel 分支
- Agent 状态全局化：新增 `app/src/stores/agent.ts`（Pinia）承接 `useChat.ts` 全部状态与 `send/abort/clear`；`ai_token`/`ai_done` 事件监听移到 store 内注册一次；`useChat.ts` 删除。面板切换/关闭不再丢对话

## D. Agent 关联远程服务器 + 远程执行（手动确认 + 自动模式开关）

**会话关联**
- agent store `watch(activeTab)`：活跃 tab 为已连接 ssh → 自动绑定该 sessionId；ChatPanel 头部显示 `user@host`；**未连接任何 SSH 时显示「请先连接 SSH 服务器」空状态 + 「新建连接」按钮（打开统一弹窗）+ 禁用输入框**
- 有连接时 `includeContext` 默认开启；保留多会话手动下拉切换

**后端（crates）**
- `AppState` 新增 `session_meta: HashMap<String, String>`（`session_connect` 时写 `root@192.168.1.10:22`，`session_disconnect` 清理；`SshSession` 只有 addr 不含用户名，故在 connect 处注册）
- `ai-core/src/provider/context.rs`：`Context` 增加 `server_info: Option<String>`（**`#[serde(default)]`**，遵循项目 IPC serde 约定）；`to_system_prompt()` 增加「## 目标服务器」段落 + 命令执行协议：需要检查服务器时输出 ` ```run ` 单条命令块，用户确认后执行并回传输出；要求命令非交互、危险操作需说明风险
- `desktop/src/commands/ai.rs` `ai_chat_send`：从 `session_meta` 注入 `server_info`

**远程执行（复用现有 `session_exec` 命令，session.rs:31）**
- `MessageBubble.vue` 解析 assistant 消息中的 ` ```run ` 块 → 渲染命令卡片（等宽命令 + 「在服务器执行」按钮）
- 执行流程：点击 → 危险命令黑名单（rm -rf / mkfs / dd / shutdown / reboot 等）命中先二次确认 → `invoke('session_exec', {sessionId, command})` → 输出超 8KB 截断 → 插入 `role: 'tool'` 终端风格气泡 → 自动回传对话（作为带 `[命令执行结果]` 前缀的消息发给 LLM 继续分析）
- 自动模式：ChatPanel 头部开关（默认关，localStorage 持久化）；开启时 `ai_done` 后自动逐条执行新 assistant 消息中的 run 块（每块带已执行标记防重）
- `types/ai.ts` `ChatMessage` 扩展 `role: 'tool'`（仅前端展示层，发往后端仍为 user 消息）

## 实施顺序

1. stores：`ui.ts`（弹窗状态）、`agent.ts`（全局对话状态）、layout 加 `rightTab`
2. ConnectDialog 弹窗 + 各入口收敛 + 删两处内联表单 + 取消空 tab
3. `connectProfileSmart` 统一连接 + 去重弹窗 + 修 ConnectForm addTab
4. RightPanel（Agent/监控切换栏）+ ChatPanel 移入 + 删 chat tab kind
5. 后端 session_meta + Context.server_info + prompt 协议

7. 清理遗留（SessionKind、TerminalView 空表单状态）
