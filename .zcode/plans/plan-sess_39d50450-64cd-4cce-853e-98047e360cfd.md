# Agent 助手多会话历史记录

## 现状与目标
- 现状:Agent 助手是**单会话**——`stores/agent.ts` 的 `messages` 纯内存,`chatSessionId` 每次启动随机生成;后端 `ChatProvider.history` 是全局单份内存 History。清空或重启后对话全部丢失,也无法并存多段对话。
- 目标:Agent 窗口顶部增加**会话 Tab 页**:多会话新建/切换/删除,消息落 SQLite,重启后可查看历史并继续对话(LLM 上下文一并恢复)。

## 改动清单(按仓库惯例拆 3 个 commit,conventional 前缀 + 中文正文)

### Commit 1 — `feat(storage)`: Agent 会话/消息持久化
- `crates/desktop/src/storage/sqlite.rs`
  - `init_schema` 新增两张幂等表:
    - `agent_chats(id TEXT PK, title TEXT, created_at INTEGER, updated_at INTEGER)` + `idx(updated_at DESC)`
    - `agent_chat_messages(id TEXT PK, chat_id TEXT, role TEXT, content TEXT, error INTEGER DEFAULT 0, created_at INTEGER)` + `idx(chat_id)`
    - 消息 id 用前端生成的 id(TEXT),重启后消息 id 稳定,runStates key 不失效
  - 结构体 `AgentChat` / `AgentChatMessage`(serde `rename_all = "camelCase"`)
  - `SqliteStorage` 方法:`list_chats`(新→旧)/ `create_chat` / `rename_chat` / `delete_chat`(级联删消息)/ `list_messages(chat_id)` / `append_message`(内部 touch `updated_at`;title 为空且 role=user 时取 content 首行前 20 字做标题)/ `clear_chat_messages(chat_id)`
- `crates/desktop/src/commands/agent_chat.rs`(新文件):`agent_chat_list/create/delete/rename/messages/append/clear_messages` 薄封装,仿 `snippet.rs`;`append` 返回更新后的 `AgentChat` 供前端同步标题与排序
- `crates/desktop/src/main.rs` 注册命令 + `commands/mod.rs` 声明;sqlite in-memory 单测覆盖 CRUD/级联删/自动标题
- 遵守 IPC serde 约定:命令参数 snake_case、返回 struct camelCase

### Commit 2 — `feat(ai-core)`: Chat 历史按会话隔离 + 从库恢复
- `crates/ai-core/src/provider/mod.rs`:`AgentProvider::send` 与 `clear` 增加首参 `session: &str`
- `provider/chat.rs`:`history` 改为 `Mutex<HashMap<String, History>>`;新增固有方法 `has_history(session)` / `seed_history(session, Vec<Message>)`(仅无条目时写入);`strip_think` 改 pub 供复用
- `provider/work.rs`:占位实现同步改签名(忽略 session)
- `crates/desktop/src/commands/ai.rs`:
  - `ai_chat_send`:调用前惰性恢复——`!has_history(sid)` 时从 SQLite 读该会话消息转 LLM 消息后 seed:user→user;assistant→`strip_think(content)`(error=1 跳过);tool→user(`[命令执行结果]\n{content}`,与在线链路格式一致)
  - `ai_chat_clear` 加 `session_id` 参数,只清指定会话

### Commit 3 — `feat(ui)`: Agent 面板多会话 Tab
- `app/src/types/ai.ts`:`AgentChat` 类型;`services/ai.ts`(或新 `agentChat.ts`):7 个 invoke 封装
- `app/src/stores/agent.ts` 改造:
  - `chats: ref<AgentChat[]>`(updated_at 倒序)、`activeChatId`、`messagesByChat: Record<chatId, ChatMessage[]>` 内存缓存,切换按需从库加载
  - AI sessionId 直接用 chatId;`ai_token`/`ai_done` 按 `p.sessionId` 路由到对应会话的消息数组——**生成中切 Tab 流式不丢**
  - `loading` 改为 `generatingChatId: string | null`(后端单生成:发送前全局判忙,停止按钮只在生成中的会话显示)
  - 落库时机:user/tool 消息即时 append;assistant 在 `ai_done` 定稿时 append;首次发送懒创建会话
  - `newChat` / `switchChat` / `deleteChat`(删激活会话自动切最近一个)/ `clear` 语义改为"清空当前会话消息"(删库中消息 + `ai_chat_clear(chatId)`)
  - 启动时拉取 chats,激活最近会话并加载消息
- `app/src/components/ai/ChatPanel.vue`:header 上方加 Tab 条——横排会话 chip(空标题显示「新会话」、超长截断),激活高亮,激活项 × 删除(NPopconfirm 确认),末尾「+」新建;原「清空」按钮文案改「清空当前会话消息」
