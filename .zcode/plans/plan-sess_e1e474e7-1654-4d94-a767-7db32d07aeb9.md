# 推荐功能全量规划（9 个功能，分 9 个阶段，每阶段自动提交）

现有基础（勘察结论）：`russh-sftp 2.0` 已在 ssh-core 依赖中但未使用；`keys.rs` 的 generate/parse 是 stub；sqlite 采用幂等 `CREATE TABLE IF NOT EXISTS` 模式；AI 的 `Context.terminal_output` 字段从未被填充（注入点明确）；主题硬编码 darkTheme。

## 阶段 1：SFTP 文件管理器
- ssh-core：`SshSession::open_sftp()`（channel_open_session + `russh_sftp::client::SftpSession`），封装 list/read/write/mkdir/rm/rename
- desktop：新 `commands/sftp.rs`（sftp_list/upload/download/mkdir/remove/rename，走 AppError），注册 main.rs
- 前端：TerminalView 内新增可折叠文件面板（文件树 + 面包屑 + 拖拽上传 + 下载进度），⌘F 打开
- 提交：`feat(sftp): SFTP 文件管理器`

## 阶段 2：命令片段 & 历史同步
- sqlite 新表 `command_snippets`（id, name, command, tags, created_at）、`command_history`（id, session_id, command, created_at）
- 终端输入行解析（ssh-core TerminalStream 或前端 onData 缓冲回车行）写入历史
- 前端：⌘K 命令面板（naive-ui modal + 模糊搜索：片段/历史/主机切换），片段可收藏；SideBar 无侵入
- 提交：`feat(snippets): 命令片段与历史 + ⌘K 命令面板`

## 阶段 3：深浅主题切换
- `stores/theme.ts`（light/dark/auto + localStorage + 监听 prefers-color-scheme）
- main.css 拆 `.theme-dark` / `.theme-light` 两套 token；App.vue themeOverrides 按 store 计算（null 替代 darkTheme）
- SettingsView 新增「外观」区块；xterm 主题联动
- 提交：`feat(theme): 深浅色主题切换`

## 阶段 4：监控告警规则
- sqlite 新表 `alert_rules`（id, name, metric, op, threshold, enabled, cooldown_sec）
- sampler.rs 每次采样后评估规则，超阈值 emit `alert_fired`（含冷却期去重）
- 前端：MonitorPanel 新增「告警」区（规则 CRUD + 最近触发记录 + 触发时系统通知/TabBar 红点）
- 提交：`feat(alerts): 监控告警规则`

## 阶段 5：AI 上下文增强
- ssh-core terminal.rs：增加环形 scrollback 缓冲（最近 ~200 行）
- desktop ai.rs：`ai_chat_send` 前从 AppState 注入活跃会话 scrollback + 最近监控快照（CPU/内存/负载）到 Context；Context 增 metrics 字段
- ChatPanel：上下文来源选择（终端输出 / 监控指标 / 两者），修复 sshSessionId 未赋值问题
- 提交：`feat(ai): 注入终端输出与监控指标上下文`

## 阶段 6：终端分屏
- TabItem 无需改动；TerminalView 内部支持 pane 列表（水平/垂直 split，≤4 pane），每 pane 可绑定不同会话
- SplitPane 容器组件（CSS flex + 拖拽分割条，复用 MonitorPanel 的 resize 逻辑）
- 提交：`feat(terminal): 终端分屏`

## 阶段 7：SSH 密钥管理器
- 补全 ssh-core keys.rs：ed25519/rsa 生成（russh-keys）、指纹计算、公钥导出
- 私钥存 OS keyring（复用 keyring.rs 模式），公钥/指纹存 sqlite 新表 `ssh_keys`
- SettingsView 新增「密钥」区块（生成/导入/复制公钥/删除）；ConnectForm 认证方式可选已存密钥
- 提交：`feat(keys): SSH 密钥管理器`

## 阶段 8：会话分组与搜索
- `session_profiles.extra` JSON 增加 `group` 字段（无需 schema 迁移）
- SideBar：顶部搜索框（名称/host 过滤）+ 按 group 分组的可折叠分组头；ConnectForm 增加分组输入
- 提交：`feat(sidebar): 会话分组与搜索`

## 阶段 9：终端命令自动补全
- 前端首次连接后经 `exec("compgen -c | sort -u")` 拉取远端命令表（缓存到 profile 维度），叠加本地片段/历史
- xterm attach 自定义 suggest 层（输入时下方浮动候选列表，Tab/↑↓ 选择）
- 提交：`feat(autocomplete): 终端命令补全`

## 每阶段验证与提交
- Rust：`cargo build && cargo test`；前端：`pnpm build`（vue-tsc）
- 通过即 `git commit`（遵循每阶段提交偏好），失败则修复后重验再提交
- 全部完成后 dev server 浏览器验证关键页面渲染
